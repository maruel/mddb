# mddb

mddb is a Notion-like document and database system: a Go backend with an embedded SolidJS frontend, storing
data as Markdown, JSONL, and assets in git repositories. Read [backend/AGENTS.md](backend/AGENTS.md),
[frontend/AGENTS.md](frontend/AGENTS.md), or [e2e/AGENTS.md](e2e/AGENTS.md) before editing those trees.

## Workflow

- Run `make git-hooks` before the first change.
- After a change, run `make fix`, then `make verify`, the read-only pre-push gate. `make test` runs Go and
  frontend unit tests; `make coverage` reports their coverage.
- After a UI or API change, also run `make test-e2e`. The server log is at `data-e2e/server.log`.
- After a visible UI change, run `make screenshots-update` and commit the documentation captures.
- `make` lists every target and its cost.
- `.editorconfig` sets indentation and width. Ruff repeats the width in `pyproject.toml` because it does not
  read `.editorconfig`.
- The first-line comment of each file feeds the file index below; update it when the file's purpose changes.
- Plans are `docs/PLAN_*.md` files in the owning module.
- User and integration guides live at docs.mddb.app (the `docs.mddb.app` repository). Keep durable contracts in
  comments beside the owning source, not in Markdown.

## Roll Go Mode

Pick a Git commit and roll both the `github.com/maruel/gomode` Go module and the `@maruel/gomode` package in
`package.json` to it.

## Python tools

Run Python tools and repository scripts with `uv run --locked`.
Run `uv lock` after changing Python dependencies.
